# Security

Этот репозиторий публичный.

## Запрещено коммитить

- реальные пароли, токены, API keys;
- приватные сертификаты и ключи;
- внутренние IP-адреса и production-топологию без отдельного решения;
- реальные SID и учётные записи сотрудников;
- raw security/event evidence;
- выгрузки ACL и AD;
- содержимое документов;
- production environment files;
- архивы диагностик.

Production-specific evidence и инфраструктурный контекст хранятся в приватном инфраструктурном репозитории.

## Сообщение об уязвимости

Не публикуйте секреты или эксплуатационные детали в публичном issue. Используйте приватный канал владельца репозитория.
