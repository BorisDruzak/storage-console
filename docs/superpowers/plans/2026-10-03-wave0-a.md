# Wave 0A Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Воспроизводимый monorepo foundation, запускаемый fresh clone через Docker Compose.

**Architecture:** Nginx обслуживает Web и проксирует API. API и worker используют PostgreSQL; Alembic выполняется отдельным одноразовым migration service. Worker публикует heartbeat, который health check сверяет с часами БД.

**Tech Stack:** Python 3.13, FastAPI/Pydantic v2, SQLAlchemy 2, Alembic, PostgreSQL 16, React/TypeScript/Vite, TanStack Query/Table, react-i18next, Vitest/Playwright.

**Spec:** docs/spec/storage-control-plane-v0.1.md; docs/tasks/wave0-a-foundation.md.

## Global Constraints

- ru-RU default, en-US fallback; user-facing React strings только через i18n keys.
- Observe/diagnose/recommend; no autonomous remediation, live collectors, filesystem monitoring, Redis or document content.
- Missing/stale data никогда не отображаются как healthy.
- UTC timezone-aware database timestamps.
- Production configuration и secrets вне публичного Git.
- Работа в main и push разрешены пользователем; последовательное выполнение в текущем checkout.

## Review Focus

- DB недоступна: API readiness возвращает 503, без credentials в ответе.
- Worker остановлен: heartbeat становится stale и health check падает.
- Нет DSN: startup работает; logs структурированы без чувствительных полей.
- Missing translation key или hardcoded JSX text: quality checks падают.
- Чистая БД: migration работает; повторный запуск не разрушает persistent state.
