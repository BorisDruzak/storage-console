> Execute with superpowers:executing-plans; full task scope remains docs/tasks/wave0-c-web-ru.md.

Goal: complete Russian Web Console shell and domain pages over typed API abstraction.
Spec: docs/tasks/wave0-c-web-ru.md and docs/spec/storage-control-plane-v0.1.md.
Baseline: 9a171fd4dcf7bd730dd875bc49c60b16bb502435; Wave0B published and verified.

Architecture: retain existing React/Vite/i18next/TanStack Query stack. Typed responses come from
published runtime OpenAPI; validate untrusted JSON at the client boundary. Read-only data queries,
no filesystem/DB access or infrastructure mutation. Independent requests load in parallel.
Navigation/deep links and filters persist in URL; business timezone is configurable locally.
Missing, loading, failed, stale and current data remain distinct. API readiness is process
availability, never storage health. Unimplemented domain providers show explicit unavailable
evidence rather than synthetic production results; subsequent waves supply those providers.
